PHIL MUNENE PERSONAL WEBSITE
============================

Files:
- index.html  : website content
- style.css   : design and responsive layout
- script.js   : mobile menu and scroll animations

To view:
1. Keep all three files in the same folder.
2. Double-click index.html, or open it with Chrome/Edge.

To publish:
Upload the three files to a static hosting service such as GitHub Pages, Netlify, or Vercel.
